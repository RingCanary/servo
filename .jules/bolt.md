## 2025-02-12 - [Replace Vec::contains with HashSet::insert for O(1) deduplication in SupportedPropertyNames]
**Learning:** In `components/script/dom`, DOM property deduplication in methods like `SupportedPropertyNames` (used across `HTMLCollection`, `HTMLFormElement`, and `NamedNodeMap`) used `Vec::contains()` and `Vec::iter().any()`, which perform O(N) linear scans. This becomes O(N^2) complexity when building the returned list, particularly expensive when there's an overhead for creating the comparison elements (like allocating DOMString for comparison). Using a `HashSet` tracking elements reduces this to O(1) lookup complexity, avoiding `DOMString` allocations on duplicate properties.
**Action:** When filtering or deduplicating elements to create a list of supported property names, use `HashSet::insert` to perform O(1) tracking and conditionally build the final vector to improve iteration performance and eliminate duplicate `DOMString` allocation.
