## 2025-02-12 - Atom Empty Checking & HashSet Deduplication
**Learning:** Found an (N^2)$ `.iter().any()` deduplication pattern with unnecessary `.to_string().is_empty()` heap allocations in `components/script/dom/html/htmlformelement.rs`. Atoms internally point to an interned `str` or similar structure, so checking `.is_empty()` directly avoids `String` creation. Cloning an `Atom` is cheap (atomic ref increment), making it highly suitable for `HashSet` insertion during string deduplication passes, bringing deduplication complexity to (N)$.
**Action:** Always prefer `.is_empty()` directly on `Atom` rather than casting to `String` via `.to_string()`. Use `HashSet` combined with cheap `Atom::clone()` to implement (N)$ unique filtering loops instead of (N^2)$ linear searches.
