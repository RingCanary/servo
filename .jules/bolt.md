## 2024-05-18 - [Optimize SupportedPropertyNames Deduplication]
**Learning:** In Servo's DOM implementation (e.g. `HTMLCollection`, `HTMLFormElement`, `NamedNodeMap`), `SupportedPropertyNames` loops over elements and deduplicates ID/name strings using O(N) array checks like `!vec.contains(...)` or `!vec.iter().any(...)`, resulting in O(N^2) complexity. Furthermore, some code converted `Atom` strings to `String` and checked `is_empty()` instead of using `Atom::is_empty()` directly.
**Action:** When performing deduplication passes over DOM collections where IDs/names are `Atom`s or string slices, use `std::collections::HashSet` for O(1) membership testing to drop complexity from O(N^2) to O(N). Additionally, always call native `.is_empty()` on `Atom` strings instead of converting them via `.to_string().is_empty()` to prevent extraneous heap allocations.
