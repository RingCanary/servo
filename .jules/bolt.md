## 2024-05-14 - Optimize DOM Collections SupportedPropertyNames Deduplication
**Learning:** In the `script` component, deduplicating elements for `SupportedPropertyNames` (in `HTMLCollection`, `NamedNodeMap`, and `HTMLFormElement`) was previously using `Vec::contains` or `.iter().any()`, which are O(N) operations within an O(N) loop, leading to O(N^2) complexity. Using a `std::collections::HashSet` to track seen items (`Atom`s or `&str`) converts this to O(N) time complexity. Furthermore, checking uniqueness via `HashSet` *before* allocating `DOMString::from()` avoids heap allocations for duplicate entries. Cloning `Atom`s (interned strings) is very cheap and suitable for `HashSet` insertion.
**Action:** When iterating over DOM collections in `components/script` to return deduplicated lists, always use a `HashSet` to track seen items (`Atom`s or `&str`) instead of `Vec::contains` or `.iter().any()`. Defer string allocations (like `DOMString`) until the item is confirmed to be unique.
