## 2025-04-14 - [O(N^2) to O(N) deduplication in DOM Collection SupportedPropertyNames]
**Learning:** Found multiple implementations of `SupportedPropertyNames` (e.g. `HTMLCollection`, `HTMLFormElement`, `NamedNodeMap`) manually checking for duplicates in collections (e.g. using `Vec::contains` or `.iter().any()`), causing `O(N^2)` iteration overhead over the properties. `stylo_atoms::Atom` supports fast clones and can easily be placed in `std::collections::HashSet`.
**Action:** When performing duplicate filtering in property/name iterations within `script/dom`, track seen items using a `std::collections::HashSet` containing `Atom`s (or `&str` references if `Atom` isn't used) to guarantee fast `O(1)` duplicate checks instead of using `contains` on accumulating property vectors.
